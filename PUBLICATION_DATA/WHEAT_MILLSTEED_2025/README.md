# WHEAT_MILLSTEED_2025

Processed data package for manuscript figure and supplementary figure reproducibility.

## Manuscript context

This package supports a manuscript currently under submission and contains processed outputs from:

- input sample identifier: `D02266B1` (raw `.gef` file is not included in this repository)
- run folder: `RESULTS_D02266B1_20260828_0925`

Primary study reference:

- Millsteed, T., Kainer, D., Sullivan, R., Sun, X., Li, K.L., Mao, L., Macdonald, A., Henry, R.J., 2025. Spatial Transcriptomics of Developing Wheat Seed Reveals Concentric Gene Expression Zones and Subgenome Biased Expression of Key Genes. Plant Biotechnology Journal 23, 5934-5949. https://doi.org/10.1111/pbi.70351
- https://onlinelibrary.wiley.com/doi/full/10.1111/pbi.70351

## Folder-to-figure mapping

- `PLOTS/`
  - Main figure panels and supplementary figure plots generated by the primary pipeline.
  - Includes QC, annotation overlays, marker summaries, volcano panels, and interest-gene visualizations.

- `CLUSTERING/`
  - Per-cluster spatial panels (LOUVAIN, LEIDEN, SPATIAL_LEIDEN).
  - Used for supplementary cluster-level figure panels.

- `EXPORTS/`
  - Core processed tables used to regenerate figure statistics and overlays.
  - Includes cell metadata, HVG list, marker metadata, PCA variance, UMAP coordinates, and final network edge/node tables.

- `NETWORK/`
  - hdWGCNA-derived module edge/node files and checkpoint object.
  - Used for network figures and Cytoscape/network filtering workflows.

- `STATISTICAL_ANALYSIS/`
  - Aggregated statistical outputs used in summary and supplementary plots.

- `LOGS/` and `REPORTS/`
  - Processing summaries and analysis report used to trace software/runtime context.

## Included and intentionally excluded files

Included here are reusable processed files that are practical to version inside GitHub.

Excluded from this package are very large intermediates that exceed practical repository limits for standard Git workflows, including:

- full `.h5ad` export
- full HVG expression matrix table
- complete all-marker tables for all clustering modes
- full `INTEREST_ANALYSIS` bulk marker dumps
- raw input `.gef` files (sensitive/raw source data)

These exclusions do not block regeneration of the published figure outputs included under `PLOTS/` and `CLUSTERING/`.
